## envr edit-config

Edit your config with your default editor

```
envr edit-config [flags]
```

### Options

```
  -h, --help          show this documentation
  -c, --config-file   config file (default "~/.envr/config.json")
      --color         Whether or not to colorize output (default 'auto')
```
